# muestras/

Aquí van las fotos reales de formularios (en blanco y llenos) y su `verdad.csv`.

**Nada de esta carpeta se versiona** (solo este README): son datos de pacientes ficticios con la
letra real de la usuaria y, en blanco, instrumentos con posibles derechos de autor. El
`.gitignore` excluye todo salvo este archivo. Los tests de CI usan el formulario sintético
(`plantillas_demo/`), nunca estas muestras.
